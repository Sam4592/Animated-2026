## Overview

3D, Grease Pencil 2D, compositor and video editor in one (5.2.3 LTS, 22 Oct 2026) — C++, Python. GitHub is a mirror; development lives on projects.blender.org.

## Install

The GitHub README does not include an end-user install command. It links the [main website](https://www.blender.org) and says a clone of the GitHub mirror can hit Git LFS errors unless you set `GIT_LFS_SKIP_SMUDGE=1`.

The official download page lists installers for Windows, Windows ARM, macOS Apple Silicon, Linux, Steam, and source. When checked on 26 Oct 2026 it showed **v5.2.3 LTS**, matching the version in this catalog.

Building from source is documented at [developer.blender.org](https://developer.blender.org/docs/handbook/building_blender/), not as the way to install the app.

> **Check this.** Download options from blender.org/download, checked 26 Oct 2026. No package-manager command is printed on that page, so none is repeated here.

## Quick start

Install the build for your OS, then open Blender. Grease Pencil, the compositor, and the video sequence editor are part of the same application. The user manual is [docs.blender.org](https://docs.blender.org/manual/en/latest/index.html).
