## Overview

Simple hand-drawn frame-by-frame — C++, Qt. No rigging or tweening.

## Install

The README says to download from the [official site](https://www.pencil2d.org/download/) or GitHub releases. The download page, checked 26 Oct 2026, offers **v0.7.2** for Windows 7+, macOS 10.14+ (Intel and a separate mac build), and Linux AppImages. It also prints:

```
sudo pacman -S pencil2d
sudo apt-get install pencil2d
sudo dnf install Pencil2D
flatpak install flathub org.pencil2d.Pencil2D
brew install --cask pencil2d
```

Those are alternative package routes on the same page (Arch, Debian/Ubuntu, Fedora, Flatpak, Homebrew). Use one, not all of them.

> **Check this.** Links and commands from pencil2d.org/download, checked 26 Oct 2026.

## Quick start

Open the app and draw on frames. The project has no rigging or tweening tools, which is why the catalog lists that as the caveat.
