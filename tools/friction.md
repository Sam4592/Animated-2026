## Install

The README links build instructions, not a binary install command. The project site’s download section, checked 26 Oct 2026, offers **v1.0.0-rc.3** for Windows (setup exe and a 7z), Linux (AppImage), and macOS (dmg), from the GitHub release assets. Example of the Windows setup linked there:

```
https://github.com/friction2d/friction/releases/download/v1.0.0-rc.3/friction-1.0.0-rc.3-setup-win64.exe
```

The same section links `Friction-1.0.0-rc.3-x86_64.AppImage` and `Friction-1.0.0-rc.3.dmg`. Snapshots are listed separately.

> **Check this.** Release files from friction.graphics, checked 26 Oct 2026. The README itself only documents compiling.
