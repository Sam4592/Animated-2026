## Overview

Cross-platform editing with keyframed filters — C++, Qt, MLT. An editor, not an animation tool.

## Install

The README says binaries are at [shotcut.org/download](https://www.shotcut.org/download/). That page, checked 26 Oct 2026, lists version 26.9.27 builds for Windows 10/11 (Intel/AMD and ARM), macOS 12+, and Linux (portable tar and AppImage). Minimum Windows 10 build named there is 1809. Linux snap, from that page:

```
snap install shotcut --classic
```

> **Check this.** Snap command and OS list from shotcut.org/download, which the README links. Checked 26 Oct 2026.

## Quick start

Open Shotcut and edit on the timeline. Keyframed filters are part of the editor. The README’s compile steps (`cmake`, then `cmake --install .`) are for building, not for a normal install.
