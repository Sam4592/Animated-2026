# Tools

One page per tool. The grouped list on the [catalog home](../README.md#catalog) is the same set.

## Code-driven

Describe a video in code or HTML and render a file.

- [HyperFrames](hyperframes.md) — HTML/CSS + seekable animations to deterministic MP4; built for AI coding agents
- [Remotion](remotion.md) — Templated, data-driven videos in React at scale (v4.0.539, 26 Oct 2026)
- [Motion Canvas](motion-canvas.md) — Code-authored explainer animations with a live preview editor
- [Revideo](revideo.md) — Motion Canvas fork aimed at programmatic rendering and APIs
- [Diffusion Studio Core](diffusion-studio.md) — In-browser video compositing engine

## Pipeline & CLI

Script encoding, math explainers, and batch edits.

- [ManimGL (3b1b)](manimgl.md) — 3Blue1Brown's own engine with interactive preview
- [FFmpeg](ffmpeg.md) — The encoding/filters backbone under nearly every tool here
- [Manim (Community)](manim.md) — Math and technical explainer animations (v0.22.0, 8 Oct 2026)
- [MoviePy](moviepy.md) — Scripted cutting, compositing, captions and titles
- [editly](editly.md) — Declarative JSON5 spec or CLI to a finished slideshow-style video

## 2D/3D apps

Desktop programs for drawing, rigging, and 3D.

- [Blender](blender.md) — 3D, Grease Pencil 2D, compositor and video editor in one (5.2.3 LTS, 22 Oct 2026)
- [Krita](krita.md) — Painted frame-by-frame animation
- [OpenToonz](opentoonz.md) — Production 2D cel and cut-out animation
- [Synfig Studio](synfig.md) — Vector tweening and bone rigging without frame-by-frame drawing
- [Pencil2D](pencil2d.md) — Simple hand-drawn frame-by-frame
- [Tahoma2D](tahoma2d.md) — OpenToonz-based 2D plus stop motion, friendlier defaults

## Motion graphics

Editors and compositors with keyframes or nodes.

- [Shotcut](shotcut.md) — Cross-platform editing with keyframed filters
- [OpenShot](openshot.md) — Beginner editing with keyframe animation
- [Kdenlive](kdenlive.md) — Assembling, keyframed effects, titles and final edit
- [Natron](natron.md) — Node-based compositing, After Effects/Nuke-like
- [Friction](friction.md) — After Effects-style vector motion graphics (enve fork)

## AI video

Local models and node UIs that generate or animate footage.

- [ComfyUI](comfyui.md) — Node UI that runs Wan, LTX, Hunyuan and other video models (v0.42.1, 19 Oct 2026)
- [Open-Sora](open-sora.md) — Fully open model including training code (Open-Sora 2.0, 11B)
- [LivePortrait](liveportrait.md) — Animating a still portrait from a driving video
- [Wan 2.2](wan22.md) — Text/image-to-video, Wan2.2-Animate character animation, speech-to-video
- [FramePack](framepack.md) — Practical image-to-video diffusion on consumer GPUs
- [CogVideoX](cogvideox.md) — Text/image-to-video research models
- [AnimateDiff](animatediff.md) — Motion modules for Stable Diffusion image models
- [LTX-Video](ltx-video.md) — Earlier, permissively licensed LTX model
- [WanGP](wangp.md) — Low-VRAM app for Wan, LTX, Hunyuan and more
- [LTX-2](ltx-2.md) — Video generation with synchronized audio (LTX-2.5 weights, v1.5.0)
- [ComfyUI-WanVideoWrapper](wanvideo-wrapper.md) — Community Wan nodes for ComfyUI
- [ToonCrafter](tooncrafter.md) — Generating in-between frames for cartoons
- [HunyuanVideo 1.5](hunyuanvideo.md) — 8.3B text/image-to-video; 14 GB minimum with offloading

## Lottie & vector

Play vector animations exported from After Effects.

- [lottie-web](lottie-web.md) — Playing After Effects-exported Lottie animations
