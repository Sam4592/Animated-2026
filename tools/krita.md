## Overview

Painted frame-by-frame animation — C++, Qt. A painting app first; animation tools are basic.

## Install

The GitHub README says this repository is a mirror of KDE Invent and points at [krita.org](https://www.krita.org). It does not include a user install command.

The download page, checked 26 Oct 2026, offers **Krita 5.3.4.1** (released Wednesday, 7 October 2026): a Windows installer, a macOS installer, and a Linux 64-bit AppImage, plus Steam and the Mac App Store.

> **Check this.** Versions and installers from krita.org/en/download, checked 26 Oct 2026.

## Quick start

Animation is documented in the [user manual](https://docs.krita.org/en/user_manual.html). The README’s nightly-build links are for testing, not the stable install.
