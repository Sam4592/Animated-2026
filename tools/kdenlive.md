## Overview

Assembling, keyframed effects, titles and final edit — C++, MLT. An editor, not an animation tool.

## Install

The README does not include an install command. It says downloads for stable releases and daily builds are on [kdenlive.org](https://kdenlive.org).

The download page, checked 26 Oct 2026, lists **26.08.2**. The Windows standalone build says it requires Windows 10 or newer. Linux options on that page include an AppImage. macOS is a separate column on the same page. Daily builds are marked for testing.

> **Check this.** Version and Windows 10 note from kdenlive.org/download, checked 26 Oct 2026. No single shell command is shown for every OS, so none is invented here.

## Quick start

Open Kdenlive, import clips, and use titles plus keyframed effects for the final edit. Developer build steps in the README are for contributors.
