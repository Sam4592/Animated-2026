## Overview

Motion Canvas fork aimed at programmatic rendering and APIs — TypeScript. Repo moved from redotvideo to the midrender org; small community.

## Install

The README’s getting started command:

```
npm init @revideo@latest
```

The README says headless rendering needs Node and a headless browser. It does not list a minimum Node version.

> **Check this.** Command from the Revideo README, checked 26 Oct 2026.

## Quick start

A scene is a TypeScript generator passed to `makeScene2D`. Render with [`renderVideo()`](https://docs.re.video/renderer/renderVideo/). Telemetry can be turned off with `DISABLE_TELEMETRY=true`, as stated in the README.
