## Overview

Code-authored explainer animations with a live preview editor — TypeScript. Last tagged release v3.17.2 is from Dec 2024.

## Install

The repository README does not include install commands. It points at the [getting started guide](https://motion-canvas.io/docs/quickstart), which says Node.js 16 or greater and then:

```
npm init @motion-canvas@latest
```

If that fails on an old npm, the same page gives `npm exec @motion-canvas/create@latest` (the bug it mentions was fixed in npm 8.15.1). After the prompts:

```
cd <project-path>
npm install
npm start
```

> **Check this.** Steps from motion-canvas.io/docs/quickstart, linked from the README and checked 26 Oct 2026.

## Quick start

The guide says the editor is at `http://localhost:9000/`. The scaffold can install an image-sequence exporter, a Video (FFmpeg) exporter, or both. The scene file it creates is `src/scenes/example.tsx`.
