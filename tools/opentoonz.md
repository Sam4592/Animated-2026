## Install

The README says to download the latest installer from [opentoonz.github.io](https://opentoonz.github.io/e/index.html). Older and nightly builds are on the GitHub releases page. It does not publish a package-manager command.

That site’s system requirements, checked 26 Oct 2026:

- Windows: Windows 7 SP1, 8.1, or 10, 64-bit; Intel Core i series; 4 GB RAM or more; 500 MB free; 1280×1024 or higher.
- macOS: macOS 10.14 or later; Intel Core i series; 4 GB RAM or more; 500 MB free; 1280×1024 or higher.

The same page does not list a Linux requirement block. Linux build steps are in the repository’s `doc/how_to_build_linux.md`.

> **Check this.** Installer location from the README; hardware list from opentoonz.github.io, both checked 26 Oct 2026.
