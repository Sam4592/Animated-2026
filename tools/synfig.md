## Install

The README says Synfig Studio is available for Windows, Linux, and macOS, and links the [installation guide](https://synfig.readthedocs.io/en/latest/installation.html) instead of printing commands. That guide says:

- Windows: download the .exe and run the wizard.
- Linux: download the AppImage, mark it executable, and double-click it.
- macOS: download the .dmg, drag Synfig Studio to Applications, and open it (the guide also covers the unidentified-developer prompt).

The stable download page is [synfig.org/download-stable](https://www.synfig.org/download-stable/). Checked 26 Oct 2026, that page says Synfig is free under GPLv3 and that payment is optional. It did not show a direct installer URL in the page HTML, so this catalog does not invent one.
