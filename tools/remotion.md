## Install

The README says: if Node.js is already installed, run the scaffolder. Otherwise follow the [installation page](https://www.remotion.dev/docs/).

```
npx create-video@latest
```

> **Check this.** Command from the Remotion README, checked 26 Oct 2026. The README does not list a Node.js version number; it points at the docs for a full install.

The scaffolder asks how you want to start a React video project. Rendering options (Node.js, Lambda, client-side) are documented at [remotion.dev/docs](https://www.remotion.dev/docs).
