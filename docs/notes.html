Methodology

Sources and notes

This site lists 35 tools. Stars and last-push dates were taken from the GitHub API on 26 Oct 2026 and are stored as published in the research notes (for example “72.9k”, not a live recount). Licenses, “best for” lines, stacks, and caveats are from that same pass. This page does not add tools that were left out of it.

Install steps

Install and quick-start commands were copied from each project’s GitHub README, or from the official install page that README links, on 26 Oct 2026. Where a README has no end-user command, the tool page says so and links the download page that was actually fetched. Commands that could not be read from those pages are not filled in from memory.

Stalled or left out

  • Theatre.js: Apache-2.0 motion editor for the web, no pushes since Aug 2024.
  • Olive: GPL-3.0 video editor, no pushes since Dec 2024.
  • AnimateDiff, ToonCrafter, FramePack, and editly are still listed because they remain usable, but they have no recent pushes. See each tool’s caveat.
  • SkyReels-V2 was left out because its license could not be confirmed from the repo.
