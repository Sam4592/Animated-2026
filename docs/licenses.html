License gotchas

Using these tools to make a video is often less restricted than shipping the tool or the model weights. The notes below are the ones that change a buying or shipping decision. They are not legal advice.

Remotion

Remotion License: free for individuals, non-profits, and for-profits up to 3 employees. Larger companies need a company license. The planned v5 license also counts contractors toward team size.

LICENSE.md · v5 license change (PR 3750)

LTX-2

LTX-2.x Community License: commercial entities with $10M+ annual revenue need a paid commercial license.

LICENSE-2_x

HunyuanVideo 1.5

Tencent Hunyuan Community License: does not apply in the EU, UK, or South Korea, and has an acceptable-use policy.

License

WanGP

WanGP Community License 2.0: free to use and sell outputs. No reselling, white-labeling, or paid hosting of the app itself without a commercial license.

LICENSE.txt

GPL apps

ComfyUI, Blender, Kdenlive, and the other GPL apps: using them to make videos is unrestricted. The copyleft only matters if you redistribute modified code.

Code versus model weights

An Apache or MIT code license on CogVideoX, LivePortrait, or a ComfyUI workflow does not cover the model weights or bundled third-party models. Check each weight file before commercial use.

Also in a project README

Diffusion Studio Core is listed here as MPL-2.0. Its README, checked 26 Oct 2026, says rendered video keeps a “Made with Diffusion Studio” watermark unless you buy a license key. That condition is not in the summary table above.
