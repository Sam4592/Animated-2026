Open-source tools for animated video

35 open-source and source-available tools for animated video. Stars and last push are from the GitHub API on 26 Oct 2026.

The biggest shift in 2026 is agent-driven video: HyperFrames, HeyGen’s Apache-2.0 HTML-to-video framework, already has 72.9k stars and shipped v0.8.206 on 26 Oct 2026. For generated footage, Wan 2.2 inside ComfyUI is the most permissive strong option in this set.

Each tool page has install steps copied from that project’s README or the official docs the README points to. Nothing here is a company product, and there are no testimonials.
