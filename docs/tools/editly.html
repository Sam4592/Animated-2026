Overview

Declarative JSON5 spec or CLI to a finished slideshow-style video

Install

README requirements: Windows, macOS, or Linux; Node.js (latest LTS recommended, and v12.16.2 or newer on macOS); ffmpeg and ffprobe on PATH. Linux may need the system packages listed by headless-gl. The package is ESM only.

npm i -g editly

Check this. Command and requirements from the editly README, checked 26 Oct 2026.

Quick start

editly --help

A one-line slideshow from the README (inputs are your own files):

editly \
  title:'My video' \
  clip1.mov \
  title:'THE END' \
  --fast \
  --audio-file-path /path/to/music.mp3

Or editly my-spec.json5 --fast --out output.gif.
