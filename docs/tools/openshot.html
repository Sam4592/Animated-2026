Install

The README says the quickest start is a pre-built installer from openshot.org/download, and it mentions the Daily Builds section of that page.

Checked 26 Oct 2026, the download page offers a Linux AppImage for v4.0.1 and this snap command:

sudo snap install openshot-qt

The same page has Windows and macOS tabs. Daily-build filenames change often, so they are not copied here.
