https://github.com/friction2d/friction/releases/download/v1.0.0-rc.3/friction-1.0.0-rc.3-setup-win64.exe

The same section links Friction-1.0.0-rc.3-x86_64.AppImage and Friction-1.0.0-rc.3.dmg. Snapshots are listed separately.
