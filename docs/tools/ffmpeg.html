Overview

The encoding/filters backbone under nearly every tool here — C. Enabling GPL components changes redistribution duties.

Install

The GitHub README does not contain install commands. It says GitHub is not the review process and points at ffmpeg.org. The download page says FFmpeg only publishes source, and gives this clone of the official git server:

git clone https://git.ffmpeg.org/ffmpeg.git ffmpeg

That page links already-built packages rather than one project-owned installer:

  • Linux: Debian and Ubuntu official packages, Fedora and RHEL via RPM Fusion, plus static builds at BtbN/FFmpeg-Builds.
  • Windows: builds from gyan.dev and BtbN.
  • macOS: static builds at evermeet.cx/ffmpeg.

Check this. Clone command and package links from ffmpeg.org/download.html, checked 26 Oct 2026. This catalog does not add a brew or apt command the download page does not show.

Quick start

After ffmpeg is on your PATH, the tool manual is ffmpeg.org/ffmpeg.html. A version check is ffmpeg -version. The project’s own README does not include a sample encode command.
