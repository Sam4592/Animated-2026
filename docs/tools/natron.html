Overview

Node-based compositing, After Effects/Nuke-like — C++. Slow-moving development.

Install

README requirements: GNU/Linux, macOS, or Windows, and a 32-bit x86 or 64-bit x86-64 CPU. Hardware-accelerated rendering wants OpenGL 2.0; otherwise software rendering is available (on Linux, LIBGL_ALWAYS_SOFTWARE=1).

Binaries for Linux, Windows, and macOS are on GitHub releases and the website. Linux Flatpak from the README:

flatpak install fr.natron.Natron

Check this. Requirements and Flatpak command from the Natron README, checked 26 Oct 2026.

Quick start

Launch Natron and build a node graph. The README’s source-build files (INSTALL_LINUX.md, INSTALL_MACOS.md) are for compiling.
